## Verification Gates

Before calling a P0 complete:

- Run one thief and one spectator on separate devices.
- Confirm the thief cannot inspect hidden guard/camera state through the client payload or renderer.
- Confirm audio failure still leaves a playable visual/text path.
- Confirm a command is visible, acknowledged, and produces the intended result.
- Confirm escape and death transition the shared room and permit rematch.
- Refresh a spectator and confirm reconnect behavior.
- Test touch controls with the onboarding card, look pad, room leave, and result CTA.
- Test provider failure, slow network, and a spectator leaving mid-round.
